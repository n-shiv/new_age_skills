# New-Age Skills — Quick Revision

## Why Work Is Changing
- **AI & automation** → faster work, automated tasks, changing roles
- **Digital transformation** → new tools, new skills, new career paths
- **Workplace disruption** → changing work models, employee needs, inclusion
- **Career shifts** → reskilling, role transitions, continuous learning

## Skills That Matter

| Skill | Keywords to Remember |
|---|---|
| **Digital & AI** | Use digital tools; understand AI; improve productivity |
| **Critical thinking** | Question assumptions; check evidence; connect information; make reasoned decisions |
| **Intellectual curiosity** | Ask questions; explore; self-learn; lifelong learning |
| **Adaptability** | Adjust to change; learn new skills; embrace new roles |
| **Resilience** | Handle setbacks; manage uncertainty; recover and move forward |
| **Problem-solving** | Define the problem; structure the approach; prioritize tasks |
| **Communication** | Know the audience; structure the message; drive action |
| **Relationships & well-being** | Build trust; collaborate; maintain well-being |

## What Employers Need
- **Agility** — respond quickly
- **Good questions** — challenge assumptions; clarify needs
- **Judgment** — add value beyond automation
- **Communication** — explain clearly; influence action
- **Continuous learning** — update skills regularly

## Career Principles
- **Work with AI**, not against it
- **Automate routine tasks**; focus on human judgment, creativity, and relationships
- **Learn continuously** through work, courses, and practice
- **Prepare proactively** for change instead of only reacting
- **Stay flexible** about roles, skills, and career paths

## One-Glance Summary
**Future-ready = Digital/AI skills + Critical thinking + Curiosity + Adaptability + Resilience + Problem-solving + Communication + Relationships & well-being**
